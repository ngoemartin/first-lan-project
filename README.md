First LAN Project: Cisco Packet Tracer

1. Project Overview

This is my first networking project. I built a Local Area Network (LAN) using Cisco Packet Tracer to understand how computers communicate with each other over a network.

2. Objectives

- Understand how a Local Area Network works.
- Configure IPv4 addresses and subnet masks.
- Connect computers using an Ethernet switch.
- Test network connectivity using the ping command.

3. Tools Used

- Cisco Packet Tracer

4. Network Topology

The network consists of two computers connected to a network switch.

- PC0
- PC1
- One Ethernet switch

5. IP Address Configuration

Device| IP Address| Subnet Mask
PC0| 192.168.1.10| 255.255.255.0
PC1| 192.168.1.20| 255.255.255.0

Both computers belong to the same subnet.

6. Connectivity Test

I used the following command on PC0 to test connectivity with PC1:

"ping 192.168.1.20"

Result: PC0 successfully received a reply from PC1.

This confirmed that the two computers could communicate over the local network.

7. What I Learned

Through this project, I learned how to:

- Build a basic LAN using a switch.
- Configure IPv4 addresses and subnet masks.
- Understand communication between devices on the same subnet.
- Test network connectivity using ping.
- Work with Cisco Packet Tracer.

8. Future Improvements

I plan to extend this project by learning subnetting, configuring routers, and connecting multiple networks.
